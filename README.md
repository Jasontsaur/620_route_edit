# 620 路線工作室

TWB 2026 四極點620 的繁體中文路線編輯器。可編輯路線、管理補給及檢錄點、匯入 Garmin 檔案、匯出 Edge 課程，並保存不同版本。

桌機與手機的路線圖例、高度圖均有「展開／收合」按鈕，預設收合，兩個面板可獨立開關。手機版以地圖為主要畫面，兩個面板移至地圖下方。展開面板不會遮住地圖，向下捲動可查看內容。瀏覽模式隱藏操作提示，編輯模式保留；高度圖按容器寬度繪製，刻度過多時可橫向捲動。旋轉手機時地圖會重新計算大小及可見里程範圍。

網站公開瀏覽，知道網址即可免登入使用。匿名版本需要保留 Cookie；清除 Cookie、使用無痕模式或換裝置會取得新的版本空間，請用 JSON 匯出／匯入移轉。舊帳號版本保持隔離，不會公開給匿名訪客。

## 使用方式

1. 開啟頁面即同時載入兩條預設路線：橘色的「520 騎乘紀錄（瘦身）」（3,892 點、約 516.47km）為目前編輯路線，藍色虛線的「TWB 2026 四極點620」（2,658 點、約 602.50km）為參考路線。圖例與高程圖都顯示兩條路線，另保留 TWB 起終點和六個檢錄點，不必再次上傳紀錄。
2. 「編輯路線」：放大至白色節點出現，拖曳節點、點擊插入、右鍵刪除。「延伸路線」依點擊順序增加末端。編輯以直線連接，沒有道路自動貼齊或自動轉彎指示。
3. 「加入點位」：點擊地圖設定名稱、類型、座標與備註；此模式也能拖曳既有點位。點選站點查看自四極點620起點起算的里程、距目前編輯軌跡的距離與關門時間。
4. 「復原／重做」可回復最近 35 次修改；快捷鍵 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z。
5. 「儲存版本」會建立不可覆寫的新版本，雲端保存完整路線及點位，免登入時以瀏覽器的匿名 Cookie 識別碼區隔；「版本紀錄」可載入、比較里程，再編輯成分支。頁面列出最近 100 個版本。重新開頁預設顯示這兩條路線，可從版本紀錄載入保存內容。
6. 「匯入軌跡」支援 GPX、TCX、FIT 或本程式 JSON 備份。GPX／TCX／FIT 匯入後成為橘色的目前編輯路線，原路線與沿途點位保留，原軌跡以不同顏色虛線疊圖。地圖圖例列出各路線名稱及長度，可移除參考路線並用復原返回；最多保留 8 條參考路線。JSON 匯入會還原備份中的完整圖層。Garmin 活動紀錄可保留 GPS 幾何、高度、鐘面時刻、速度與10秒平均功率；不保存活動日期、心率等其他感測資料。
7. 點數過多時使用路線概覽的「簡化軌跡」，可設定 1–50m 水平容差，預覽點數後套用，並可復原。

未儲存的編輯只存在目前頁面；離開時會提醒。可用「完整編輯備份」下載 JSON 保留完整點位資訊。

所有位置里程固定以內建「TWB 2026 四極點620」基準軌跡的起點為 0km，沿該軌跡累計。沿途點位依 GPS 位置投影到四極點620的里程，由小到大排列；詳情與列表使用相同數值。離基準較遠的點位仍顯示最近基準路段的里程，並另行標示距基準的距離，涵蓋尚待精確定位的檢錄點。公告里程保留在來源資料中，頁面站點統一顯示基準軌跡計算值。雲端版本與 JSON 備份包含參考路線；側欄顯示目前路線對應的四極點620里程範圍，並另外標示目前軌跡的實際長度。Garmin 匯出仍使用橘色路線的實際課程幾何與長度，符合車表課程距離的格式；位置里程與路線長度分別標示。「全線」會涵蓋所有路線，即使原路線與匯入路線重疊，寬虛線仍可與橘色實線區分。

地圖沿四極點620基準路線每 50km 顯示一個里程標籤（50、100、150…，只顯示數字），按實際軌跡長度計算並定位在相鄰軌跡點之間；不把 GPS 分段空隙算入里程。編輯、匯入、復原、載入版本、移除參考圖層或改名後，標籤仍固定於相同基準位置。Google Maps 與備用底圖均支援，標籤不會擋住點擊或拖曳編輯。

高程圖同時呈現所有路線，顏色與地圖相同。移動或縮放地圖後，圖表自動以地圖內可見路段的最低至最高基準里程作為橫軸範圍，包含跨越視窗邊界、但端點在畫面外的路段；所有曲線共用此範圍並裁切畫面外資料。保留每 50km 刻度，較小範圍補上邊界里程；「全線」恢復全線範圍。若畫面中沒有可對齊路段，顯示提示。分離的可見路段以共同里程上下限顯示，GPS 分段空隙仍不連線。高程對齊基準固定為內建四極點620軌跡，取消可切換的基準選單。基準獨立於可編輯路線與參考圖層，即使移除四極點620的可見圖層、匯入不含它的 JSON 備份或載入舊版本，仍使用相同起點與累計里程。橫軸為基準路線的里程，每 50km 標示刻度；其他路線的 GPS 位置投影到基準的相近路段，起點不同或反向騎乘不會把各自的 0km 錯當成同一位置。縱軸為原檔高度（公尺），共用高度刻度。缺少高度、GPS 斷點、或距基準超過 1km 的路段留空，圖例會標示無資料或無法對齊。局部峰谷保留在繪圖取樣中；窄螢幕可橫向捲動查看完整刻度。這不會改寫路線座標、原始高度或 Garmin 匯出內容。

滑鼠滾輪縮放改為每次半級（0.5 級）；Google Maps 啟用小數縮放，備用 Leaflet 地圖也支援半級。兩種底圖共用滾輪處理，按像素／行／頁正規化，觸控板小幅輸入會累積，40ms 合併快速事件；滑鼠所在位置維持在同一畫面位置。超過200ms停頓會清除剩餘量，反向滾動立即改向，並限制於底圖支援的縮放上下限。面板內的滾輪用於面板捲動，不會縮放底圖。

內建「520 騎乘紀錄（瘦身）」的3,892個保留軌跡點已從原始GPX補回實際紀錄時刻，以台灣時間（Asia/Taipei）儲存 HH:MM:SS，沒有公開活動日期或心率等其他感測紀錄；速度及10秒平均功率詳見下方說明。瀏覽模式下滑鼠移到該路線上，會顯示最近保留紀錄點的時間；點擊可固定提示，點地圖空白處關閉。Google Maps與備用底圖皆支援，路線轉為參考圖層後也可查看。顯示的是實際GPS點的時間，不在兩點之間推估。新增、拖曳後不具原紀錄時間的點位不會補造時間。雲端版本及完整JSON備份保留 recordedTime；較早儲存且未包含此欄位的版本不會顯示時間，請載入最新預設路線。FIT／TCX 匯出的課程時間仍按原本規則生成。

## 自動儲存與歷史版本

全站共用同一份最新工作路線。以私人編輯連結開啟後，匯入 GPX／TCX／FIT／JSON、編輯軌跡、點位、名稱及參考圖層，都會自動保存到後端 D1；停止編輯約1.2秒後儲存，匯入與回復版本則立即排入儲存。原檔不會上傳，保存的是匯入、瘦身後的路線資料，包含所有圖層、點位及已解析的時間／速度／功率。任何裝置開啟原網址，都會讀取後端最新內容；未曾儲存時才顯示內建雙路線。頁面保留載入時的快照，已開啟的其他頁面需重新載入才能取得最新路線。

「儲存版本」另存一份不會被後續編輯改寫的歷史快照，供回復及比較長度。每次匯入與回復也會建立快照，一般自動儲存只更新最新工作內容。回復會保存為新的共用狀態與快照，舊快照仍保留。共用版本紀錄列出最近100筆；不會自動刪除更早的版本。

原網址免登入、公開可看。更新功能預設需要私人編輯連結（網址片段 #route-edit=…），首次開啟即換取一年有效的 HttpOnly／SameSite=Strict 編輯 Cookie，並移除網址片段；不使用 localStorage 保存管理權限。編輯者可按「複製編輯連結」帶到自己的其他裝置，請勿公開分享此連結。秘密環境變數 SHARED_ROUTE_EDIT_KEY 是256-bit隨機金鑰，僅存於主機；更換金鑰並部署即可撤銷舊連結與 Cookie。不要把真實金鑰寫入程式、README或GitHub。若站台擁有者明確選擇所有訪客可編輯，才設定 SHARED_ROUTE_PUBLIC_EDIT=true；預設未設定。公開瀏覽與更新權限彼此分開，沒有登入畫面。

儲存採版本比對，兩台裝置同時更新時，較舊頁面會顯示衝突並停止自動寫入，不會默默覆蓋新內容。先匯出 JSON 備份，再按「重新載入」取得最新內容。連線失敗時保留目前修改，按「重試儲存」；重試同一操作不會重複建立匯入版本。只有收到後端成功回應才標示已保存，關閉尚未保存的頁面會提醒。初始讀取失敗只顯示內建路線與錯誤提示，不能把備用內容自動覆蓋到後端。

舊版的私人歷史版本仍依原瀏覽器 Cookie 或既有登入身分區隔。版本來源選單可查看「此瀏覽器的舊版私人版本」，不會自動公開；按「載入並共用」並確認後才轉成公開共用路線。更新之前僅留在舊頁面記憶體、未儲存過的匯入內容，需再匯入一次。

新增端點 GET／POST /api/shared-route、GET /api/shared-route/versions，以及私人編輯連結的 /api/shared-route/access。新資料表 shared_route_state 由追加的 Drizzle migration 建立；現有私人版本與地圖設定不變。所有寫入檢查編輯權限、同來源與 CSRF，路線內容仍限制1.8MB，超過時請先簡化或移除不需要的圖層。共用最新路線和歷史版本存於站台資料庫，GitHub僅保存程式與公開內建資料。

## Google Maps

金鑰改由後端資料庫 map_settings 共用保存，所有裝置讀取同一設定。網站擁有者透過私密管理連結開啟設定頁，貼上金鑰後按「儲存金鑰到後端」，再重新檢查設定。公開設定面板只顯示狀態與說明，無法修改金鑰。保留管理輸入功能，之後可再移除。

管理連結以 256-bit 隨機能力權杖授權，權杖與期限分別存於 Sites 的秘密環境變數 MAPS_SETUP_TOKEN、MAPS_SETUP_EXPIRES_AT（Unix 毫秒）；本次管理連結有效 24 小時。連結權杖放在 URL fragment，開頁立即從網址列移除，只留在頁面記憶體，不寫入 Cookie、localStorage 或 GitHub，也不由公開 API 回傳。POST /api/maps-config 必須通過權杖、期限及同來源檢查，限制 4KB JSON 請求與有效金鑰格式；只有儲存成功才移除舊瀏覽器金鑰。連結請視同管理密碼，不要分享。過期後由主機擁有者更新秘密值並重新部署，開啟新的管理連結。

GET /api/maps-config 不快取地回傳 Maps JavaScript API 的瀏覽器金鑰，管理權杖永遠不回傳。也可設定秘密環境變數 GOOGLE_MAPS_API_KEY 作為未填入資料庫前的備用；資料庫設定優先。不要使用 NEXT_PUBLIC_ 前綴，不要把真實金鑰寫入原始碼或 GitHub。Sites 秘密環境變數變更後需重新部署。

啟用 **Maps JavaScript API**、專案計費，並將金鑰的應用程式限制設為網站 HTTP referrer、API 限制設為 Maps JavaScript API。正式網站來源為 https://twb-620-route-editor.jasontsaur.chatgpt.site/*；設定面板會顯示目前來源。瀏覽器型 Maps JavaScript API 載入時必須使用金鑰，後端存放不會讓金鑰在瀏覽器完全不可見，請依 [Google 官方安全說明](https://developers.google.com/maps/api-security-best-practices) 限制使用來源。

Google Maps 成功載入後，地圖右上方「全線」下方的選單提供「地圖／衛星／地形」。切換時保留路線、點位與高程圖。備用 OpenStreetMap 不顯示 Google 圖層選單。未設定後端金鑰時會暫用此瀏覽器以前保存的金鑰，僅讀取、不自動上傳或新增本機設定；沒有舊金鑰則使用 OpenStreetMap。重新檢查設定會重新整理頁面，請先儲存編輯。

本機測試可在忽略追蹤的 .dev.vars 設定 GOOGLE_MAPS_API_KEY，使用 Wrangler 本機執行；請勿提交此檔案。正式 Sites 環境變數需由主機管理，不是由 .dev.vars 部署。

## 匯出到 Garmin Edge

「匯出 Garmin」提供 FIT 課程、TCX、GPX 及完整 JSON 備份。

- 建議使用 FIT 或 TCX 保留課程點。下載後開啟 Garmin Connect 網頁的「訓練與規劃 → 路線」，選擇匯入，再「傳送至裝置」並同步 Edge。
- 支援 USB 檔案傳輸的 Edge 可將 FIT 放入 `Garmin/NewFiles`，安全退出後重新啟動，實際步驟依機型。
- GPX 包含軌跡與獨立 waypoint；不同 Garmin 匯入流程可能不顯示 waypoint。Connect 也可能重算或忽略 FIT/TCX 課程點，請在 Edge 檢查。
- FIT/TCX 的時間為 25km/h 推算的課程時間，非實際活動紀錄；沒有自動產生轉彎提示。含斷開軌跡的路線請用 GPX；FIT 匯出會拒絕跨空隙連線。

已通過官方 FIT SDK 解碼、CRC 與檔案往返測試，尚未以實體 Edge 驗證。

開啟 `http://127.0.0.1:5173/`。網站免登入即可使用；資料保存在忽略追蹤的 `.wrangler/state`。上線使用 D1 儲存全站共用的最新路線與新版本；舊私人版本仍依原識別方式區隔，不會自動公開。本機編輯請在忽略追蹤的 .dev.vars 設定測試用 SHARED_ROUTE_EDIT_KEY，或僅在本機設定 SHARED_ROUTE_PUBLIC_EDIT=true。

```sh
npm run lint:app
npm run typecheck
npm test
npm run build
```

React 19、Vinext／Vite、Leaflet、Google Maps JavaScript API、Garmin FIT SDK、Cloudflare D1／Drizzle。`lib/route.ts` 管理幾何與點位，`lib/files.ts` 處理 Garmin 檔案，`app/api/maps-config/route.ts` 管理共用地圖設定；`app/api/shared-route/` 管理最新共用路線及歷史快照，`app/api/versions/route.ts` 保留舊私人版本；`lib/version-owner.ts` 管理匿名儲存識別碼。

每次匯入上限 100MB、原始單條最多 100 萬軌跡點、500 點位；原始點數超過 12,000 點會自動瘦身後再驗證及匯入，逐步採用 2–50m 位置／1–10m 高度容差，目標 12,000 點，瘦身後仍不得超過 50,000 點。保留各 GPS 分段端點、轉彎、主要高程變化、缺失高度邊界，並每 500m 保留定位錨點；無法保留必要斷點而縮至上限時，會提示分段匯入。GPX／TCX／FIT 與 JSON 備份（含參考圖層）皆適用，點位不會自動刪除。支援 Web Worker 的瀏覽器在背景解析及簡化，並顯示處理階段及前後點數；GPX／TCX 以串流 XML 解析，不建立整棵 DOM，也不保留心率等感測擴充資料，以降低記憶體用量。原始檔案不會改寫。簡化後量測里程可能減少，原檔請保留供比對。雲端單版 JSON 上限仍為 1.8MB，多次匯入的參考圖層過多時可移除不需要的圖層。金鑰、資料庫、後端地圖設定、個人路線版本與開發快取不會提交 GitHub，GitHub 同步的是程式和公開基準資料。

## 520 速度與10秒平均功率

時間提示另顯示速度（km/h）與10秒平均功率（W）。速度優先使用來源裝置的速度；缺少時，以相鄰原始GPS點的距離／實際時間差估算，標示「GPS估算」，不跨分段、暫停或超過10秒的缺口。計算發生在瘦身前；原始GPS幾何、高度、點數、時刻與里程保持不變。

10秒平均功率以該點結束的前10秒為窗口，按實際取樣時間加權；各讀值代表其前一個取樣間隔。需要完整10秒的有效資料，0W滑行會納入，缺值、超過2秒的取樣間隔、時間倒退或計時暫停會重建窗口，不把缺值當成0W。FIT活動檔與Garmin TCX活動檔支援來源速度及功率；規劃用FIT／TCX課程的推算時間不會當成原始騎乘時刻。原始時間戳和單筆功率只在處理過程使用，不加入JSON備份或雲端路線版本。

520內建資料已用同次「雙塔2025.tcx」補齊：原始72,461筆紀錄的時間戳與GPS座標逐筆比對完全一致，維持相同的3,892個保留點、座標、高度與時刻。所有3,892點有裝置速度；3,694點有完整10秒功率平均，其中249點為有效0W。其餘198點缺少完整窗口，標示「資料不足」。不公開TCX原檔、活動日期、完整時間戳、心率或其他感測資料。
